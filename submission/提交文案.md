## 二、作品介绍

### 完整版（约 400 字）

「Bug 博物馆 / Museum of Bugs」是一个只收藏失败的线上展厅，写给所有被 bug 折腾过的开发者。

**使用场景**：修完一个坑、趁记忆还热的那五分钟。起名、选形制（空指针 / 时区 / 并发 / 玄学……）、填一句死因，一分钟完成入藏登记。系统会按年份自动断代，写出一段馆藏说明，再用程序化生成的几何图形把它铸成一件「文物」，摆进你的展柜。

**核心玩法**分两层。一是「自己的馆」——每个 bug 都是一件展品，可以导出 1000×1400 的展签图，挑六件还能生成一张竖版策展海报。二是「世界厅」——收入 27 件真实事故，从 php2shell、Log4Shell、心脏出血，到阿丽亚娜 5 号、骑士资本、一条命令删掉 S3，覆盖 PHP / Java / Go / JavaScript / Python / C / C++ / Rust / Ada 九种语言，可按语言筛选，也能一键借进自己的馆里，和你的 bug 并排挂。

**体验方式**：打开即用，无需注册、不联网，所有藏品只存在浏览器本地。支持中英双语与「夜展 / 日展」两套主题，桌面与手机均可。

### 精简版（约 120 字）

一个把 bug 当文物收藏的线上博物馆。修完的坑用一分钟登记入藏：选形制、填死因，系统自动断代、写展签、铸成几何文物，还能导出展签图与策展海报。另有「世界厅」收录 27 件真实事故，覆盖九种语言，可借进展柜与自己的 bug 并排展出。无需注册，数据只在本地。
