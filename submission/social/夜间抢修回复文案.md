# 一夜 php2shell · 可直接发的回复文案

**背景（自己心里有数就行）**：2026-10-21，PHP 发布 8.2.35 / 8.3.36 / 8.4.27 / 8.5.12，修掉 CVE-2026-109618 与 CVE-2026-109619，CVSS 9.2。前者是内存耗尽时 `longjmp` 打断，请求内存没初始化就被拿去用；后者是请求内存已经释放、全局状态还指着它，**同一个 worker 的下一个请求会接住这块地**。

后一条是整个晚上最好笑的素材——它不是漏洞，是鬼故事。

## 发的分寸

- **可以写**：版本号、CVSS 分数、披露日期、技术机理的「人话版」。这些全是公开信息。
- **不要写**：任何利用细节、PoC 思路、绕过方式。
- **不要写**：「我们差点被打」——等于公开自曝当时没修。
- **不要写**：内部系统名、真实域名、同事姓名。
- **幽默的来源**：把技术细节翻译成人话（"内存不肯走"、"继承"、"超度"），不是堆网络热词。前者十年后还好笑，后者下周就过期。
